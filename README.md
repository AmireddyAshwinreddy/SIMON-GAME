# SIMON-GAME

A classic memory-based web game where the player must replicate a sequence of colors generated by the computer. As the game progresses, the sequence becomes longer and more challenging.


How to Play:


Start the Game: Press any key on your keyboard to begin.

Watch the Sequence: The game will flash a button (Red, Green, Yellow, or Purple).

Repeat: Click the buttons in the exact same order they were shown.

Level Up: Every time you successfully complete a sequence, the game adds one more flash to the pattern and increases the level.

Game Over: If you click the wrong button, the screen will flash red, and your final score (level) will be displayed. Press any key to restart!


Features:


Dynamic Leveling: Tracking system that increases difficulty in real-time.

Visual Feedback: Custom CSS animations for button flashes and "Game Over" states.

Responsive Logic: Built with Vanilla JavaScript to handle sequence generation and user input validation.

Tech Stack:


HTML5: Structure of the game board.

CSS3: Styling, layout, and flash animations.

JavaScript (ES6): Game logic, event listeners, and sequence tracking.
